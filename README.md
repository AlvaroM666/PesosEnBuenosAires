# Mis pesos en Buenos Aires

App web (PWA) para iPhone: cuánto valen los pesos chilenos en pesos argentinos (dólar blue, con oficial y tarjeta de referencia) y un registro rápido de gastos con presupuesto.

- Tipo de cambio: `dolarapi.com` (ARS por USD) y `mindicador.cl` (CLP por USD). Se guarda el último valor para usar sin conexión.
- Los gastos y el presupuesto se guardan sólo en el teléfono (localStorage de Safari).
- Instalación: abrir la URL en Safari → Compartir → «Agregar a pantalla de inicio».
